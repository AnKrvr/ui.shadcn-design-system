# Основа для ваших сайтов

Исходный код shadcn/ui, общие стили и примеры находятся в одном проекте.
Откройте **Components**, выберите компонент и попробуйте его состояния.

## Команды

- `npm ci` — установить зафиксированные зависимости.
- `npm run dev` — открыть стартовый сайт.
- `npm run storybook` — запустить этот каталог.
- `npm run build` — собрать сайт.
- `npm run build-storybook` — собрать каталог.

## Новый сайт

Скопируйте проект в новый репозиторий и замените `src/App.tsx` своими страницами.
Переиспользуйте `src/components/ui`, паттерны и семантические токены.
Изменение палитры в `src/styles/globals.css` обновляет все компоненты.

## Работа с ИИ

Опишите задачу и попросите следовать `AGENTS.md`.
Например: «Собери страницу личного кабинета из существующих компонентов,
используй семантические цвета, адаптивную сетку и обе темы».
