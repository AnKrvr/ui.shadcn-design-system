## Принятые решения

| Решение | Причина | Последствие |
| --- | --- | --- |
| Готовая основа проекта вместо отдельного npm-пакета | Цель — создавать новые сайты | Новый сайт начинается с копии этой основы |
| Пресет radix-vega | Текущая официальная нейтральная конфигурация с полным перечнем | Внешний вид может отличаться от старых примеров new-york |
| Исходники перенесены через GitHub API в отдельную ветку | В контейнере недоступны прямой git и npm | При работе в этой среде нужна синхронизация; в обычном окружении используются стандартные команды |
| Workflow только с contents: read | Автоматическая запись из bootstrap была отклонена проверкой; безопасный вариант принят | Workflow не меняет исходники и не публикует сайт |
| Общие CSS-утилиты вынесены из CLI-пакета | Сайт не зависит от генератора; убрана лишняя цепочка зависимостей | Обновление CSS-утилит выполняется явно, с сохранением лицензии |
| Сохранена правка цели на main | Пользователь изменил документ во время работы | Его изменение включено в ветку реализации |
| Локальный обход недоступного перечисления сетевых интерфейсов | Ограничение контейнера мешает запуску Vite/Storybook | Вспомогательный preload не включён в репозиторий; штатная сборка подтверждена отдельно в GitHub Actions |
| Проверка видимого элемента вместо наличия текста | Поля и кнопки с иконками могут не содержать текст | Рендеринг проверяется корректно; отдельные сценарии проверяют поведение ключевых контролов |
| Замечания о подписи, назначении и регрессии устранены вместе с паттернами | Это часть согласованных требований доступности и документации | Переносить эти замечания на будущую работу не требуется |
